# EarthShip Log Cabin House

Premium marketing site and booking experience for EarthShip Log Cabin House — a sustainable eco lodge in Timau, at the foot of Mount Kenya.

**Live site:** [https://earthship.co.ke](https://earthship.co.ke)

## Stack

- React 18 + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Express backend with Pesapal + M-Pesa booking flows

## Local development

```sh
npm install
npm run dev
```

Backend (from `/backend`):

```sh
npm install
npm start
```

## Build

```sh
npm run build
```
